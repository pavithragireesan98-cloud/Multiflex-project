# Multiflex – Local Service Booking Platform

A web-based local service booking platform designed to connect users with service workers and simplify service booking, payment, and complaint management.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Key Features

- User registration and login
- Service browsing and booking
- Worker management
- Booking and payment management
- Complaint registration and resolution
- Admin and user management
- Multi-role access control

## Database

MySQL is used to manage users, services, bookings, payments, workers, and complaint-related records.

## Project Overview

The system provides a structured platform for managing local service bookings and related transactions while maintaining data consistency across different user roles.
